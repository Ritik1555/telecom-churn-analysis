# Telecom Customer Churn Analysis & Simulation

A data engineering and analysis pipeline that simulates realistic telecom subscriber metrics, handles storage using an SQLite database configuration, and explores behavioral features that drive customer churn.

## 🚀 Key Insights Explored
* **Contract Risks:** Investigating the drastic churn variances between Month-to-Month contracts and long-term commitments.
* **Support Friction:** Visualizing how the lack of technical support correlates directly with higher user churn rates.

## 🛠️ Tech Stack & Skills Demonstrated
* **Python (Pandas & NumPy):** Data cleansing, simulation pipeline, and feature engineering.
* **SQL (SQLite):** Database schema loading, connection structures, and analysis queries.
* **Matplotlib & Seaborn:** Custom-styled data visualizations and export workflows.
